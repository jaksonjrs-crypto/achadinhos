# v1.5 — Painel Operacional 2.0
- Painel passa a funcionar como central da rotina diária.
- Atalhos em 6 etapas: Garimpar → Revisar → Preparar → Criar → Divulgar → Medir.
- Resposta do público inclui cliques dos últimos 7 dias e comparação com os 7 dias anteriores.
- Próxima ação sugerida continua baseada no estado real das ofertas.
- Atalho direto para a Central de Integrações.
- Nenhuma métrica de venda/comissão é inventada.
Sem SQL novo e sem novas variáveis de ambiente.
