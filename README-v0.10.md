# Vitrine dos Achados v0.10

Controle de qualidade antes da publicação.

- A Central mostra `Pronta para publicar` ou `Revisão necessária`.
- A revisão verifica nome, imagem, preço e link de afiliado.
- Uma oferta incompleta não pode ser publicada.
- O botão `Corrigir oferta` continua sendo o ponto de ajuste.
- Isso evita que uma oferta sem imagem volte a alimentar Vitrine, Conteúdo, Criativos e Automação.
- Nenhum SQL novo.
- Nenhuma variável de ambiente nova.
