# Vitrine dos Achados v0.8.1

Garimpo Inteligente agora inclui um avaliador interativo de candidatos.

- Nome, preço e link do produto.
- Seis notas de 1 a 5.
- Score operacional de 0 a 100.
- Classificação: Forte candidato, Candidato promissor, Revisar ou Baixa prioridade.
- Atalho para a Central de Ofertas.
- A pontuação é triagem; não promete vendas.
- Nenhum dado secreto é solicitado.
- Nenhum SQL novo.
- Nenhuma variável de ambiente nova.
