# Vitrine dos Achados v0.14 — Garimpo Inteligente 2.0

Primeiro ciclo funcional maior do novo método de desenvolvimento.

- Painel do Garimpo agora usa números reais da fila.
- Score passa a considerar avaliação manual, desconto e completude dos dados.
- Percentual de desconto é calculado automaticamente.
- Indicador de completude: nome, categoria, preço, link e imagem.
- Alerta antes de priorizar candidato incompleto.
- Cards exibem percentual OFF quando há preço anterior válido.
- Mantém busca, filtros, correção, aprovação, rejeição e promoção para oferta.
- Shopee Open API continua sem simulação: aguardando acesso real.
- Sem SQL novo.
- Sem variável de ambiente nova.
