# Vitrine dos Achados / Garimpo Afiliados — v1.0.0

Primeira versão estável do núcleo operacional.

## Incluído
- Painel Operacional.
- Garimpo Inteligente e fila persistente de candidatos.
- Avaliação, correção, aprovação e promoção de candidatos.
- Central de Ofertas com quality gate.
- Vitrine pública com categorias, transparência de afiliado e SEO.
- Redirecionamento rastreado por canal.
- Resultados 2.0 com canais e histórico recente.
- Conteúdo 2.0 e Criativos 2.0.
- Automação 2.0 como agenda operacional manual.
- Central de Integrações sem exposição de segredos.
- Proteção de catálogo aplicada ao ciclo de candidatos e ofertas.
- Tela Saúde v1 baseada em dados reais.

## Integrações posteriores
- Shopee Open API: somente quando houver acesso/documentação oficial confirmados.
- Publicação automática em redes sociais: permanece manual até conexão oficial.
- Mercado Livre: OAuth preservado; busca de produtos não é declarada como funcional.

## Banco e ambiente
Esta promoção para v1.0 não exige SQL novo nem novas variáveis de ambiente.

## Observação de validação
Foram executadas verificações estáticas de regressão sobre os módulos críticos. Este pacote não afirma um build completo do Next.js no ambiente de geração.
