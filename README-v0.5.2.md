# Vitrine dos Achados v0.5.2

Correção do rastreamento por canal na Central de Conteúdo.

- Instagram usa `channel=instagram`
- WhatsApp usa `channel=whatsapp`
- Telegram usa `channel=telegram`
- Pinterest usa `channel=pinterest`
- O seletor superior gera apenas um link personalizado e não altera os links dos blocos.
- Cada botão Copiar leva o texto e o link do canal correspondente.

Não exige SQL novo nem novas variáveis de ambiente.
