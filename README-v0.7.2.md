# Vitrine dos Achados v0.7.2

Correção de navegação global.

O menu agora é renderizado pelo `app/layout.tsx`, portanto aparece em todas as telas do App Router:
Garimpo, Produtos, Central de Ofertas, Resultados, Conteúdo, Criativos, Automação, Vitrine pública e Configurações.

Também foram removidos menus locais das páginas para evitar duplicação.

Nenhum SQL novo.
Nenhuma variável de ambiente nova.
